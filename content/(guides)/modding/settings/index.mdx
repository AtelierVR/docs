## Handler Types

| Handler | Use for |
|---------|---------|
| `ToggleHandler` | Boolean on/off switch |
| `RangeHandler` | Numeric slider (volume, FOV, distance) |
| `ButtonHandler` | Action button (reload, test, trigger) |
| `DropdownHandler` | Selection list (quality, language, device) |
