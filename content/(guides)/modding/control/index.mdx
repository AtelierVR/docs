The **nox.control** module is Nox's external control system for IDEs, dashboards,
CLI tools, and AI agents — all backed by a single operator registry.

## Transports

| Transport | Port | Path | Auth |
|-----------|------|------|------|
| **WebSocket** | `8000` | `/` | hello handshake + permissions |
| **MCP** | `8001` | `/mcp` | `Authorization: Bearer token` |
| **HTTP REST** | `8001` | `/api/*` | `Authorization: Bearer token` |

## Configuration

| Key | Default | Description |
|-----|---------|-------------|
| `settings.control.port` | `8000` | WebSocket port |
| `settings.control.http_port` | `8001` | HTTP/MCP port |
| `settings.control.mcp` | `false` | Enable MCP |
| `settings.control.token` | auto-generated | Access token |
